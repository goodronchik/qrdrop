# QRDrop на Flutter — подробная инструкция для новичка

Эта инструкция поможет вам получить готовые нативные установочные/запускаемые файлы **QRDrop** для **Android (`.apk`)**, **Windows (`.exe`)**, **macOS (`.app`)** и **Linux**, даже если вы никогда раньше не программировали.

Есть два способа:
1. **Способ 1 (рекомендуется, 5–10 минут)** — облачная сборка через **GitHub Actions**. Ничего устанавливать на компьютер не нужно, всё бесплатно соберётся на серверах GitHub, а вы просто скачаете готовые файлы.
2. **Способ 2 (локально на вашем ПК)** — если хотите собирать приложение у себя на компьютере через установленный Flutter.

---

## Способ 1: Собрать готовые файлы в облаке через GitHub (без установки программ)

### Шаг 1. Подготовьте файлы проекта
1. Скачайте архив **`qrdrop_flutter_project.zip`** и распакуйте его в любую папку на компьютере (например, на Рабочий стол в папку `qrdrop_flutter`).
2. Внутри папки должны лежать файлы `pubspec.yaml`, `.gitignore`, папка `lib` и скрытая папка `.github` (в ней находится файл `workflows/build.yml`).
   * **Важно на Windows/macOS**: папка `.github` начинается с точки, поэтому может быть скрыта. На Windows включите в Проводнике *Вид → Показать → Скрытые элементы*; на macOS нажмите `Cmd + Shift + .` (точка).

### Шаг 2. Создайте бесплатный аккаунт и репозиторий на GitHub
1. Откройте сайт **github.com** и зарегистрируйтесь (или войдите в свой аккаунт).
2. В правом верхнем углу нажмите **`+`** → **New repository** (Новый репозиторий).
3. В поле **Repository name** введите `qrdrop`.
4. Выберите **Public** (публичный — для них GitHub Actions бесплатен без ограничений) или **Private** (для приватных тоже есть 2000 бесплатных минут в месяц — этого хватит с запасом).
5. Нажмите зелёную кнопку **Create repository**.

### Шаг 3. Загрузите файлы проекта на GitHub
Есть два варианта загрузки — выберите тот, что удобнее:

**Вариант А — через браузер (если не хотите ставить Git):**
1. На странице созданного репозитория нажмите ссылку **uploading an existing file** (загрузить существующий файл).
2. Перетащите в окно браузера **содержимое** папки `qrdrop_flutter`: файл `pubspec.yaml`, папку `lib` и папку `.github`.
   * *Проверка*: убедитесь, что в списке загружаемых файлов появился `.github/workflows/build.yml`. Если браузер не подхватил скрытую папку `.github`, создайте файл вручную: нажмите **Add file → Create new file**, в поле имени введите `.github/workflows/build.yml` и вставьте туда содержимое этого файла из архива.
3. Внизу страницы нажмите зелёную кнопку **Commit changes**.

**Вариант Б — через терминал (если установлен Git):**
Откройте терминал / PowerShell внутри распакованной папки `qrdrop_flutter` и выполните:
```bash
git init
git add .
git commit -m "Initial QRDrop Flutter app"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/qrdrop.git
git push -u origin main
```

### Шаг 4. Дождитесь автоматической сборки и скачайте готовые файлы
1. В вашем репозитории на GitHub откройте вкладку **Actions** (в верхнем меню).
2. Вы увидите запущенный процесс **«Сборка QRDrop (Android, Windows, macOS, Linux)»**.
   * Если он не запустился сам, нажмите на него в левом меню и нажмите кнопку **Run workflow → Run workflow**.
3. Подождите 5–8 минут, пока рядом со всеми четырьмя платформами появятся зелёные галочки ✅.
4. Нажмите на завершённую сборку и пролистайте страницу вниз до раздела **Artifacts** — там будут 4 готовых архива:
   * **`QRDrop-Android-APK`** → внутри готовый файл `app-release.apk` для Android.
   * **`QRDrop-Windows-x64`** → внутри `qrdrop.exe` и нужные `.dll` для Windows.
   * **`QRDrop-macOS`** → внутри `qrdrop.app` для macOS.
   * **`QRDrop-Linux-x64`** → внутри готовый бинарник `qrdrop` для Linux.

## Как установить и запустить готовые файлы

### Android
1. Скопируйте `app-release.apk` на телефон и откройте его через «Файлы» / «Загрузки».
2. Android спросит разрешение на **«Установку из неизвестных источников»** — разрешите для вашего файлового менеджера и нажмите **Установить**.
3. Откройте **QRDrop** — на экране сразу появится QR-код.

### Windows
1. Распакуйте весь архив `QRDrop-Windows-x64.zip` в отдельную папку (не вытаскивайте `qrdrop.exe` отдельно — ему нужны соседние `.dll` файлы!).
2. Запустите `qrdrop.exe`.
3. Если Windows Defender SmartScreen покажет предупреждение (так как файл без платной цифровой подписи), нажмите **Подробнее → Выполнить в любом случае**.
4. Когда брандмауэр Windows спросит доступ к сети — отметьте **Частные сети** и нажмите **Разрешить доступ**.

### macOS
1. Распакуйте `QRDrop-macOS.zip` и перенесите `qrdrop.app` в папку **Программы (Applications)**.
2. При первом запуске macOS может заблокировать неподписанное приложение. Чтобы открыть его:
   * Нажмите правой кнопкой мыши по `qrdrop.app` → **Открыть** → **Открыть** (или в *Системных настройках → Конфиденциальность и безопасность* нажмите **Открыть в любом случае**).
   * Если macOS пишет «файл повреждён», откройте Терминал и выполните:
     ```bash
     xattr -cr /Applications/qrdrop.app
     ```
     После этого приложение запустится штатно.

### Linux
1. Распакуйте архив:
   ```bash
   mkdir qrdrop-linux && tar -xzf QRDrop-Linux-x64.tar.gz -C qrdrop-linux
   cd qrdrop-linux && ./qrdrop
   ```

## Как пользоваться приложением

1. Подключите оба устройства к **одной Wi-Fi сети** (или раздайте Wi-Fi с телефона на ноутбук).
2. Запустите **QRDrop** на одном из устройств — сервер стартует автоматически и покажет QR-код.
3. Нажмите **«Выбрать файлы»**, чтобы добавить файлы для отправки.
4. На втором устройстве (Android, iPhone, Windows, macOS, Linux) просто **отсканируйте QR-код камерой** и откройте ссылку в браузере — там можно скачивать файлы, отправлять новые обратно и обмениваться текстом/ссылками.
5. Если на ПК включён VPN или несколько сетевых карт и телефон не открывает страницу, выберите другой IP-адрес в выпадающем списке прямо под QR-кодом.

## Способ 2: Локальная сборка на своём компьютере (для продвинутых)

Если вы хотите собирать приложение локально без GitHub:
1. Установите **Flutter SDK** с официального сайта `docs.flutter.dev/get-started/install`.
2. Проверьте установку командой `flutter doctor`.
3. В распакованной папке `qrdrop_flutter` сгенерируйте системные файлы платформ и соберите нужную версию:

```bash
# 1. Сохраните lib и pubspec.yaml, создайте системные папки платформ
flutter create --platforms=android,windows,macos,linux --project-name qrdrop --org com.qrdrop .

# 2. Загрузите зависимости
flutter pub get

# 3. Соберите под нужную ОС (запускать на соответствующей ОС; Android собирается везде)
flutter build apk --release        # Android -> build/app/outputs/flutter-apk/app-release.apk
flutter build windows --release    # Windows -> build/windows/x64/runner/Release/
flutter build macos --release      # macOS   -> build/macos/Build/Products/Release/qrdrop.app
flutter build linux --release      # Linux   -> build/linux/x64/release/bundle/
```

> **Важно при локальной сборке:**
> - Для **Android** добавьте `<uses-permission android:name="android.permission.INTERNET"/>` в `android/app/src/main/AndroidManifest.xml`.
> - Для **macOS** добавьте ключи `com.apple.security.network.server`, `com.apple.security.network.client` и `com.apple.security.files.user-selected.read-write` со значением `<true/>` в `macos/Runner/Release.entitlements` и `DebugProfile.entitlements`.
> (В автоматической сборке GitHub Actions из Способа 1 всё это делается само.)
